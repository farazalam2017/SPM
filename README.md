# 📘 Software Project Management — BCA 3rd Year

Welcome to the **Software Project Management (SPM)** course repository for **BCA 3rd Year** students.

This repository contains **class notes, presentations, numerical problems, examples, assignments, and other study materials** covered during the course.

## 🎯 Course Objective

The objective of this course is to help students understand how software projects are **planned, estimated, scheduled, monitored, controlled, and successfully delivered**.

Students will learn both the **theoretical concepts and practical techniques** used in real-world software project management.

## 📝 How to Use This Repository

1. Read the relevant topic from the **Notes** folder.
2. Refer to the corresponding **PPT** for classroom explanations.
3. Practice numerical problems from the **Numericals** folder.
4. Complete the assigned work from the **Assignments** folder.
5. Use **Important Questions** for revision and examination preparation.

## 🎓 For Examination Preparation

Focus on:

- Understanding concepts instead of only memorizing definitions.
- Learning important formulas and their applications.
- Practicing numerical problems step-by-step.
- Preparing short-answer and long-answer questions.
- Revising diagrams, models, and project management techniques.
- Writing answers with proper headings, points, examples, and calculations.
